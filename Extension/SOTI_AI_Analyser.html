How to get started
1 Open a Salesforce case
2 On this tool, open the Case Info Panel
3 Click Sync from Salesforce
1 Attach logs with the 📄 button next to the chat box — LOG, TXT, XML, JSON, HAR or a ZIP bundle
2 The Logs section appears under Case Info once files are attached
3 Click Analyse Now — use Cancel if you need to stop it
4 A ZIP is unpacked for you, and findings are cited to the inner file

Where the relay runs
It keeps one window and reuses it, and never touches a Copilot tab you opened yourself. If a minimized window stops rendering and the composer cannot be found, it is restored automatically and retried.
Override URL (optional)
Max size of one message (characters)
How much the chat box accepts at once — not how much of the case the model gets, which is this × the parts below. If the box turns out to hold less, the relay measures it and re-splits automatically rather than failing.
Context parts per conversation
A big case is sent as several messages, and only the last one asks the question — the earlier ones are reference material the model is holding. 8 parts ≈ 92,000 characters of case. Each part is a round trip, so more parts means a slower first token. Set to 1 to send a single message, as older builds did.
